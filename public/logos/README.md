# メーカーロゴ画像の置き場所（自分でホストする場合のみ）

> 公開リポジトリや公開サイトには、各社のロゴ画像を置かないでください。各社の商標であり、多くの場合、無断での掲載・配布・改変は認められていません。

このフォルダに `<key>.svg`（または `.png` / `.webp`）を置くと、該当メーカーの写真で自動的にロゴ画像が使われます。
置かない場合は、メーカー名をフォントで組んだ「ワードマーク」が表示されます。

## ライセンスについて

各社のロゴは各社の登録商標であり、このリポジトリには同梱していません。
個人で楽しむ範囲で使う場合でも、公開サイトに配置する場合は各社のブランドガイドライン・商標の利用条件を確認してください。
アプリ内の「メーカーロゴ → 画像を登録」から登録した画像は、そのブラウザ内（IndexedDB）にのみ保存され、外部へ送信されません。
